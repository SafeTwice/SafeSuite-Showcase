# SafeSuite-Showcase

The complete SafeSuite feature demonstrator **and** a live team-server demo: this
repository is the server. Two ways in:

1. **Open from Team Server** (File menu): URL `https://github.com/SafeTwice/SafeSuite-Showcase.git`
   into an empty folder (private repo: save a GitHub token first under Team server
   settings -> Server credentials, host `github.com`).
2. Clone manually to `C:\Demo\SafeSuite-Showcase` and open `Model.ssproject`.

Start with **SHOWCASE.md** - the guided tour of every feature. `reset.cmd` restores
the bench to pristine state at any time.

# AgriPTO — EN ISO 25119 functional-safety demo (SafeSuite showcase)

Rear **PTO control system** of the (fictional) Ager Dynamics T6100 tractor,
developed end-to-end to **EN ISO 25119:2023**: HARA with AgPLr d, Category 3
dual-channel architecture, MTTFd/DC/CCF metrics computed from a real
IEC/TR 62380 prediction, SRL 2 software, safety validation, assessment and
release — all as **native SafeSuite documents** (.strdoc) plus native analysis
artifacts (**SafeFIT** .sfit, **SafeFMEA** .sfmea, **SafeTree** .fta) and PDF
deliverables.

Open `Model.ssproject` in SafeSuite and start with
`0_Guide/Feature_Guide.strdoc` — the standard documentation lives in the
structured documents, not in this file.

Generated by `demos/agri-pto-generator` in the SafeSuite repository; the
record layer (baselines, signatures, activity log) is built with the real
product code so every hash verifies.
