# Identity packs: become a member of the cast

Each folder holds one Level 1 (local-passphrase) signing identity: the identity record and the passphrase-protected key file.
The passphrase of every pack is `agripto`. From this folder's parent run

    become.cmd elena-vidal

(any folder name here) and reopen Help > Signing identity in SafeSuite. `become.cmd -restore` puts your own identity back.
The keys are fictional and worth nothing outside this demonstration; they exist so that the governed actions can be tried
as the person who holds the right to take them.
